# 设计：自定义封装查询（roq q）——保存高频模板 SQL 按名调用（2026-11-12）

## 意图

高频 SQL（按雪花 id 查单条、按状态计数、按日期范围统计）每次都要重打长 SQL 或翻
shell 历史。本功能把这类语句保存命名，之后 `roq q <名> [k=v ...]` 一步调用，人与 AI
共用同一入口。对 AI 的额外价值：保存查询是**跨会话的查询持久化**——`q list` / `q show`
让 AI 先查再用，不必每会话重拼长 SQL。

## 现状事实

- 执行链路单一入口：`parse_command` → `Command::Query(cli)` → `run_query`：
  加载配置 → `gate(&sql)` → 取 profile → `query::execute`（main.rs:44-95）。
  快捷子命令先例：只生成 SQL，走同一条闸门+审计+存档链路（红线 5）。
- 闸门 `gate()` 返回规范化 SQL；禁词表含 `SET/DO/CACHE/START/INTO` 等常见英文词
  （gate.rs:12-64），`extract_tokens` 按字母词元全大写提取（gate.rs:71-92）——
  裸模板里的 `{{set}}` 会被提取为词元 `SET` 而误判禁词。
- `strip_and_check` 引号感知：未闭合引号拒绝、字符串外 `;` 拒绝、`-- `/`#` 行注释剥离。
  推论：`'{{id}}'` 残留在引号内是**合法字符串字面量**，闸门不拦、MySQL 不报错，
  查询静默返回空结果——这是本功能最危险的静默失败模式。
- 审计行 `extra` 是自由 JSON 片段（audit.rs:47），扩展字段零破坏；存档 slug 链
  `table_slug` → `like_slug` → `"query"`（audit.rs:115-117，LIKE 标注先例 c1ed96c）。
- `config add` 成熟模式可复用：`validate_name`（字母/数字/下划线/连字符）、同名拒绝
  静默覆盖、`--update` 重录、写后回读校验、`write_file_atomic`、一配置一文件。
- SKILL.md 由 `include_str!` 随二进制分发（红线 6：不写本机路径/内网拓扑）。
- 退出码契约：0 成功 / 1 用法配置 / 2 闸门 / 3 连接执行 / 4 diff。

## 目标

1. `roq q add/list/show/remove` 管理保存查询，存 `~/.roq/queries.d/<名>.sql`
   （一查询一文件，UTF-8 原文即模板，可手工编辑）。
2. `roq q <名> [k=v ...]` 执行：`{{名}}` 宏替换 → 替换后 SQL 与手写 SQL 走**完全相同**
   的闸门+审计+存档链路。
3. 参数失误一律显式报错（缺参/多参/占位符残留/值含引号反斜杠），绝不静默错查。
4. 审计记 `saved` 名 + `params` + 替换后实际 SQL；存档文件名与文件头带查询名。
5. SKILL.md（机制说明）、README 双语、CHANGELOG `[Unreleased]` 同步。

## 非目标

- 项目级作用域（v1 仅全局 `queries.d`；查询不含凭据，后续需要再加）。
- prepared statement 绑定参数（红线排除：闸门/审计只见最终文本，绑定值不可见 → 审计失真）。
- `q add --file`（从文件读入模板）、`q edit`、`q history`、`roq diff` 集成（YAGNI；
  长模板 shell 引号可承载，编辑直接改文件）。
- 不动闸门本身。

## 反目标

- 任何绕过闸门或让审计失真的路径（替换产物必须再过闸门；审计必须记实际执行的 SQL）。
- 静默语义改变（参数问题 fail-closed 报错，对齐 LIKE 反斜杠先例 35db267）。

## 方案取舍

- **B `{{名}}` 宏替换（选定）**：契约是宏替换而非绑定参数——模板作者管语句结构、
  调用者管参数值、闸门管只读、审计管事实。引号由模板作者写好（与雪花 id 加引号的
  SKILL 惯例一致），填错引号被闸门 fail-closed 拦下。B ⊇ A：零占位符模板就是无参数 B。
- A 纯保存：被 B 完全包含，无独立存在价值。
- C `:名` 自动引号化：占位符天然有引号内（`LIKE '%{{kw}}%'`）与引号外（`LIMIT {{n}}`）
  两种位置，自动引号化只对前者成立 → 内生需要双语法，结构性复杂，否决。
- E prepared `?` 绑定：闸门/审计只见最终 SQL 文本（main.rs:60），绑定值不可见 →
  审计记的 ≠ 执行的，违背红线 4，红线排除。

## 决定

1. **命令面**：顶层 `q` 子命令族——`q add <名> "SQL模板" [--update]`、`q list`、
   `q show <名>`、`q remove <名> --yes`；执行 `roq q <名> [k=v ...]`。
   `--profile/--format/--out/--max-rows/...` 与查询完全共用（复用 `parse_query_parts`，
   顺序规则同快捷子命令：`q` 紧跟 roq，flag 放后面）。
2. **存储**：`~/.roq/queries.d/<名>.sql`，整文件即模板。add/update 为整文件原子写
   （无 config 的节手术复杂度）。文件头写一行 `-- ` 注释说明（闸门剥行注释，不妨碍执行）。
   `validate_name` 同 config 口径，另要求：不得以 `-` 开头（flag 歧义）；
   保留名 = 顶层命令词（config/log/skill/diff/tables/schema/columns/explain/q）+
   管理动词（add/list/show/remove/help）在 add 时拒绝。
3. **占位符语法**：`{{名}}`，名限 `[A-Za-z0-9_]+`；add 时校验所有 `{{...}}` 形态良构
   （`{{` 必须构成合法占位符，不留未闭合形态）；同名占位符可复用（同一值填充多处）。
4. **调用解析**：位置参数首为查询名，其余每个位置参数必须是 `k=v`（首个 `=` 切分，
   值可含 `=`）；k 的集合必须与模板占位符集合**完全一致**——缺参报错并列出所需参数名，
   多参报错。
5. **替换引擎（单遍）**：一次扫描模板，遇 `{{名}}` 查表替换，替换产物不再扫描
   （防值 `{{b}}` 被后续轮次二次展开的宏注入）；替换后断言全文无 `{{` 残留
   （fail-closed，任何漏网占位符宁可报错也不静默成字面量）。
6. **参数值约束**：拒绝含 `'` 或 `\` 的值（显式报错优于静默语义改变，提示 `''` 转义）；
   其余字符（含 `--`、`;`）不特殊化——与手写 SQL 同权，闸门兜底。
7. **保存时预检**：以哑值（固定 `1`）替换全部占位符后过 `gate()`，失败即拒绝保存
   （早暴露静态部分的禁词/语法问题；哑参替换使 `{{set}}` 类占位符名不误伤禁词）。
   写后回读：重新加载文件、内容一致、预检复跑通过。
8. **运行时**：替换后 SQL 过 `gate()`（红线 5）。**保存 ≠ 永久放行**——闸门演进会拒绝
   存量查询，这是 fail-closed 的正确行为，文档明示。
9. **审计与存档**：审计 `extra` 增 `,"saved":"名","params":{...}`（k 按模板序，值经
   `json_escape`；gate-rejected 等失败路径同样携带）；存档 slug 增第三来源：saved 查询
   名优先于 `table_slug`；存档文件头 `# ` 元信息带模板名与参数。
   **替换前失败也记审计（builder check 裁决）**：查询名不存在、缺参/多参/重复参数、
   值含 `'`/`\` 等 param 校验拦截，outcome 用新类别 `param-error`（与 gate-rejected
   同为「被拦下的尝试」，存证对称，红线 4 精神）；sql 字段记模板原文（查询不存在时
   留空）；cmd_log 的 `--outcome` 词表与 log_usage 同步补该类别。
10. **退出码**：参数/用法错=1、闸门拒绝=2、连接执行=3，不新增码（param-error 归 1）。
11. **文档**：SKILL.md 增 `q` 机制说明（只写机制不写具体查询名，红线 6）、
    README.md / README.zh-CN.md 双语同步、CHANGELOG 记 `[Unreleased]`。

## 留给实现者

- 实现基点为本地 master（2488703，含 like_slug 链与 like_pattern_literal 等 7 个提交）；
  功能分支一律基于它，与推送时机无关（推送属发版动作）。

- 模块划分：建议 `src/saved_query.rs`（模板加载/解析/替换/哑参预检，纯函数便于单测）+
  `src/cmd_q.rs`（子命令执行，遵循 cmd_*.rs 模式）；解析在 `cli.rs`（`QCmd` enum）。
- `saved` 名传入存档/审计的方式（`Cli` 增字段 vs `query::execute` 加参数，就近即可）。
- `q list` 展示形态（建议：名 + 首条非注释非空行截断摘要）；`q show` 原样输出文件内容。
- Windows 保留设备名（CON/NUL/COM1-9 等，大小写不敏感）是否纳入 `validate_name`
  （廉价加固，config 侧未做，可一并对齐或留待需要时）。
- stderr 摘要行是否附模板名（人看场景友好，`--quiet` 抑制口径与现有一致）。
